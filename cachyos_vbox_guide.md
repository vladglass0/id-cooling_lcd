# Инструкция по установке VirtualBox на CachyOS (Arch Linux) с оболочкой Fish

## Проблема
При установке VirtualBox на CachyOS модули ядра не собираются автоматически (`Module vboxdrv not found`), а DKMS ругается на отсутствие заголовков ядра (`kernel headers cannot be found`), так как установленная версия запущенного ядра устарела по сравнению с пакетами в репозитории. Оболочка `fish` не принимает Bash-синтаксис переменных.

## Решение

### Шаг 1. Полное обновление системы
Так как версии запущенного ядра и новых заголовков `linux-cachyos-headers` не совпадают, необходимо обновить систему, чтобы синхронизировать их.
```fish
sudo pacman -Syu
```

### Шаг 2. Обязательная перезагрузка
После обновления ядра необходимо загрузиться в его актуальную версию:
```fish
reboot
```

### Шаг 3. Установка заголовков и VirtualBox
Установите пакет заголовков для вашего оптимизированного ядра CachyOS и DKMS-версию модулей:
```fish
sudo pacman -S linux-cachyos-headers virtualbox virtualbox-host-dkms
```
*(Если вы используете кастомное ядро вроде `linux-cachyos-bore`, замените имя заголовков на соответствующие).*

### Шаг 4. Сборка модулей через DKMS
Запустите принудительную сборку модулей VirtualBox под новое ядро:
```fish
sudo dkms autoinstall
```

### Шаг 5. Настройка прав пользователя и запуск
Добавьте своего пользователя в группу для доступа к USB внутри виртуальных машин и активируйте модуль:
```fish
sudo gpasswd -a \$USER vboxusers
sudo modprobe vboxdrv
```

---

## Полезные команды на будущее (для Fish)
* Быстрая перезагрузка модулей VirtualBox после обновлений в CachyOS:
  ```fish
  sudo vboxreload
  ```
* Проверить имя и версию текущего запущенного ядра:
  ```fish
  uname -r
  ```
* Альтернатива от разработчиков CachyOS для лучшей производительности: **QEMU/KVM + Virt-Manager**.
